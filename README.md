## Project 1: Single-Vendor TPRM Lifecycle

### **📋 Third-Party Risk Management (TPRM) Program — Portfolio Project**

A **complete end-to-end vendor risk assessment** demonstrating the full TPRM lifecycle for a single SaaS vendor onboarding.

**Vendor Assessed:** CloudVault Data Solutions (fictional SaaS document management provider)  
**Assessing Organization:** Meridian Financial Services (fictional mid-size fintech, SOC 2 Type II obligated)  
**Data Handling:** Confidential customer PII, account numbers, and financial records  
**Frameworks:** NIST CSF 2.0, NIST SP 800-53 Rev. 5, ISO/IEC 27001:2022, SOC 2, CSA CAIQ, GDPR/CCPA

### Lifecycle Stages (9 phases):

1. **Policy & Governance** — Vendor tiering criteria, assessment cadence, risk appetite
2. **Questionnaire Design** — NIST CSF-aligned security questionnaire
3. **Vendor Response Collection** — Self-attestation responses
4. **Evidence Validation** — SOC 2 reports, audit trails, policy reviews
5. **Risk Assessment** — Control testing, gap analysis, auditor findings
6. **Risk Scoring (Inherent)** — Likelihood × Impact methodology
7. **Remediation Tracking** — Corrective Action Plans with SLAs and owners
8. **Residual Risk Scoring** — Post-remediation re-assessment
9. **Executive Reporting** — Board-level summary and vendor approval decision

### Key Demonstration:
- **End-to-end traceability**: Control questions (Q-AC-01, etc.) are traced from questionnaire → vendor response → evidence → finding → remediation → final risk rating
- **Auditor assessment methodology**: Control gap analysis, severity ratings, and remediation validation
- **Executive risk communication**: Risk acceptance documentation and leadership decision-making

## Project 2: Multi-Domain Enterprise Assessment Program

### **🏢 Extended Third-Party Security Assessment Program — CSA CCM Domain-Based TPRM**

A **structured, multi-domain supplier security assessment program** demonstrating enterprise-scale TPRM operations across 12 security control domains using the **Cloud Security Alliance (CSA) Cloud Controls Matrix (CCM v4)** taxonomy.

**Vendor Assessed:** Vantage Cloud Systems (fictional cloud-hosted ERP/business systems provider)  
**Assessing Organization:** Solstice Technologies Inc. (fictional enterprise SaaS company)  
**Assessment Type:** Extended Third-Party Security Assessment — Tier 1 Supplier  
**Control Framework:** CSA CCM v4 (12 security domains)

### Assessment Domains (12 areas):

| Code | Domain |
|---|---|
| BCR | Business Continuity Management & Operational Resilience |
| CCC | Change Control & Configuration Management |
| CEK | Cryptography, Encryption & Key Management |
| DCS | Datacenter Security |
| DSP | Data Security & Privacy Lifecycle Management |
| HRS | Human Resources Security |
| IAM | Identity & Access Management |
| IVS | Infrastructure & Virtualization Security |
| LOG | Logging & Monitoring |
| SEF | Security Incident Management, E-Discovery & Cloud Forensics |
| TVM | Threat & Vulnerability Management |
| UEM | Universal Endpoint Management |

### Program Components (9 phases):

1. **Program Overview** — Assessment workflow (kickoff → closure)
2. **Questionnaire** — CCM-aligned questionnaire across all 12 domains
3. **Finding Classification Methodology** — Structured taxonomy + SLA-driven treatment deadlines
4. **Vendor Responses** — Completed questionnaire with response scenarios (No / Yes unverified / Yes partial evidence)
5. **Evidence Repository** — Consolidated evidence log, tool inventories (MFA solutions, vulnerability scanning tools)
6. **Risk Assessment Findings** — Auditor findings with classification labels and severity ratings
7. **Risk Scoring** — Risk register with automated SLA assignment based on finding type
8. **Remediation Tracking** — CAP closure workflows against classification-driven deadlines
9. **Closure & Residual Risk** — Finding closure verification and leadership sign-off

### Key Demonstration:
- **Structured finding taxonomy**: Critical vs. Standard findings; Missing Capability vs. Technical Misconfiguration
- **SLA-driven remediation**: Different treatment deadlines based on finding severity *and* type
- **Multi-scenario response handling**: Tracks how to handle "No" answers vs. unverified claims vs. partial evidence
- **Enterprise operations**: Demonstrates how mature TPRM teams manage multiple vendors and cross-vendor inventories (MFA solutions, vulnerability tooling, etc.)
- **Executive governance**: Leadership-level risk communication and vendor approval workflows

## How to Use This Portfolio

### **For Understanding TPRM Fundamentals**
Start with **Project 1**. It walks through the complete vendor assessment lifecycle in a linear, traceable manner:
- Read sections in order (01 → 09)
- Follow a single control ID (e.g., Q-AC-01) from question through final risk rating
- Understand how auditors document findings and drive remediation

### **For Enterprise Assessment Operations**
Explore **Project 2** to see how organizations structure:
- Multi-domain assessments at scale
- Structured finding classification and SLA management
- Cross-vendor tooling inventories (reusable across supplier assessments)
- Workflow automation and evidence repositories

### **For Side-by-Side Comparison**
Both projects demonstrate:
- Questionnaire design (NIST CSF-aligned vs. CSA CCM-aligned)
- Finding documentation and risk scoring
- Remediation workflows and executive reporting

But use different vendor scenarios, frameworks, and complexity levels to show breadth of TPRM expertise.
